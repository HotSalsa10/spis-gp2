-------------
Built a machine learning model (XGBoost) that predicts daily pharmacy
drug sales for each drug category (ATC code). The model was trained on
~5 years of historical sales data and tested on the remaining ~10 months.

HOW THE MODEL WORKS
-------------------
Input:  A row with 21 features describing a specific day + drug category
Output: Predicted sales quantity for that day

The 21 features (all derived from our own sales data):

  atc_encoded     -- Drug category as a number (e.g., M01AB=0, N02BE=3)

  Calendar (7):
    day_of_week   -- Monday=0 through Sunday=6
    day_of_month  -- 1st, 2nd, ... 31st
    month         -- January=1 through December=12
    year          -- 2014, 2015, ... 2019
    week_of_year  -- Week 1 through 52
    is_weekend    -- 1 if Saturday/Sunday, 0 otherwise
    is_holiday    -- 1 if Turkish public holiday, 0 otherwise

  Lags (5) -- "What were the sales X days ago?":
    lag_1         -- Yesterday
    lag_7         -- Same day last week
    lag_14        -- Two weeks ago
    lag_28        -- Four weeks ago
    lag_365       -- Same day last year

  Rolling windows (8) -- Averages/stats over recent days:
    rolling_mean_7    -- Average sales, last 7 days
    rolling_std_7     -- Sales variability, last 7 days
    rolling_mean_14   -- Average sales, last 14 days
    rolling_mean_28   -- Average sales, last 28 days
    rolling_min_7     -- Lowest sales day in last week
    rolling_max_7     -- Highest sales day in last week
    rolling_mean_90   -- Average sales, last 3 months
    rolling_mean_365  -- Average sales, last year


TRAINING PROCESS
----------------
1. Load train.csv (14,544 rows, Jan 2014 - Dec 2018) and test.csv (2,248 rows, 2019)
2. Encode drug category names into integers (LabelEncoder)
3. Drop ~2,864 train rows from the first year where lag_365 is unavailable
   (can't look back 1 year when you only have a few months of data)
4. Run GridSearchCV with TimeSeriesSplit (5 folds) to find the best
   hyperparameters from 512 combinations
5. Evaluate on the test set using MAE, RMSE, and MAPE

Best hyperparameters found:
  - n_estimators:      200
  - max_depth:         4
  - learning_rate:     0.1
  - subsample:         1.0
  - colsample_bytree:  0.8
  - min_child_weight:  1
  - reg_alpha:         0


MODEL RESULTS
-------------
Three models were compared on the test set:

  Model               MAE       RMSE      MAPE(%)
  --------------------------------------------------
  Naive (lag_1)       4.23      7.23      98.42
  Moving Avg (7d)     2.89      4.98      67.83
  XGBoost             2.83      4.80      66.75

  MAE  = Mean Absolute Error (average prediction error in units)
  RMSE = Root Mean Squared Error (penalizes large errors more)
  MAPE = Mean Absolute Percentage Error

XGBoost beats both baselines. The naive baseline just predicts
"same as yesterday" and the moving average predicts "average of
the last 7 days."
